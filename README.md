# World Cup 2026 Consensus Predictor

Blends live match probabilities from 55+ bookmakers (The Odds API) with Polymarket prediction markets into a single consensus forecast for every FIFA World Cup 2026 match.

- No historical training data — pure market consensus
- Scoreline probabilities from Polymarket's exact-score markets (Poisson model as fallback)
- Adjustable bookmaker / Polymarket weighting via slider

## Quick start

### 1. Create a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
pip install requests pandas numpy scikit-learn xgboost lightgbm \
            streamlit plotly scipy python-dotenv
```

### 2. Set up API keys

Create a `.env` file in the project root:

```env
ODDS_API_KEY=your_key_here
FOOTBALL_DATA_KEY=your_key_here
```

| Service | Link | Free tier |
|---------|------|-----------|
| **The Odds API** | https://the-odds-api.com | 500 requests/month, 40+ bookmakers |
| **Football-Data.org** | https://football-data.org | 10 requests/min, team data |
| **Polymarket** | https://docs.polymarket.com | Fully open, no key needed |

### 3. Fetch fresh data

```bash
python 1_fetch_data.py
```

This writes `data/odds_consensus.csv` (required by the dashboard) along with team stats and historical results.

### 4. Launch the dashboard

```bash
streamlit run consensus_dashboard.py
```

Or run predictions in the terminal:

```bash
python consensus_predict.py --next 5   # next 5 matches
python consensus_predict.py --all      # all upcoming matches
```

## How the consensus model works

```
The Odds API  ──→  55+ bookmakers → implied win/draw/loss probabilities
                        │
Polymarket    ──→  per-match moneyline market  (slug index via Gamma API)
               ──→  exact-score market         ({slug}-exact-score event)
               ──→  tournament-winner market   (Bradley-Terry fallback)
                        │
                   Weighted blend (configurable in dashboard)
                        │
                   Consensus forecast + scoreline grid
```

### Polymarket data sources (priority order)

1. **Per-match moneyline** — fetched via `fetch_polymarket_match()` using the slug index
2. **Exact-score market** — fetched via `fetch_polymarket_exact_scores()` for the scoreline grid
3. **Tournament-winner fallback** — Bradley-Terry model derives match probabilities from winner odds when no per-match market exists

### Name normalisation

Bookmaker team names (e.g. "Ivory Coast", "Czech Republic", "USA") are automatically mapped to Polymarket names ("Côte d'Ivoire", "Czechia", "United States") via an alias table with exact, alias, substring, and token-level matching.

## Dashboard features

- **Match selector** — all upcoming WC 2026 matches sorted by kick-off time
- **Weight slider** — tune the bookmaker vs. Polymarket blend (0–100%)
- **Win/draw/loss bar chart** — consensus probabilities
- **Scoreline chart** — top 10 most likely scores (Polymarket exact-score market when live, Poisson model as fallback)
- **Scoreline heatmap** — full 0-3 × 0-3 probability grid
- **Source breakdown table** — bookmaker vs. Polymarket side by side

---

## Data refresh

Re-run `python 1_fetch_data.py` to pull fresh bookmaker odds before any important match day. The Polymarket data is fetched live each time the dashboard loads (cached for 5 minutes per match).
